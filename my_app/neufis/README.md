# 捏欧菲斯

私人综合工作台，适配电脑端和手机端，并可作为 PWA 安装到 vivo 桌面。

开发和维护时请遵循 [项目约束](AGENTS.md)。

## 打开方式

- 本机服务器已可用时：`http://127.0.0.1:5173/`
- 同一 Wi-Fi 下的手机：`http://192.168.6.200:5173/`
- 也可以直接打开 `index.html`

## 安装到 vivo

1. 通过 HTTPS 地址在 vivo 浏览器或 Chrome 中打开工作台。
2. 登录后点击右上角设置图标，再点击「安装到手机」；如果没有该选项，使用浏览器菜单中的「添加到桌面」。
3. 安装后从桌面的小猪图标启动，可独立窗口运行并离线打开。

PWA 安装和离线功能要求 HTTPS；局域网 `http://` 地址只用于临时访问和测试。

## 动态验证码

- 生成规则：`20230306 + 当天日期（YYYYMMDD）`
- 示例：2026 年 7 月 28 日的验证码为 `2023030620260728`
- 登录页面不会显示验证码规则或当日验证码，规则仅记录在本 README 中。
- 同一设备和浏览器首次验证成功后会长期保持登录，后续打开不再验证。
- 主动点击锁定、清除浏览器数据或更换设备后，需要重新验证一次。

## 数据

- 记录默认长期保存在当前浏览器的 `localStorage`。
- 点击「导出 Excel」会生成 Excel 可打开的 `.xls` 备份文件。
- 点击「导入 Excel」可导入本工作台导出的 `.xls`，恢复全部模块、规则和记录。
- 手机端的工作台总览、Excel 导入和导出位于右上角设置菜单中。
- 换设备前请先导出，再在新设备导入。

## AI 设置

在右上角设置菜单中打开「AI 设置」，选择厂商、填写 API Key，然后点击「保存并测试」。支持 DeepSeek、Kimi、通义千问和自定义 OpenAI 兼容接口。Kimi 与通义千问可处理图片，自定义接口首版按文本模型使用。

每家厂商的 Key 分别保存在当前浏览器的 `neufis-ai-config-v1` 中，不进入工作台主数据、Excel 备份或 Service Worker 缓存。设置页只显示已保存 Key 的末四位掩码，留空保存表示不修改；连接测试成功后才会启用。

首次调用 AI 前会显示隐私确认。待处理文本或压缩后的图片会从浏览器直接发送给所选厂商；原图和 Base64 不写入本地记录。AI 识别结果必须在预览中编辑、确认后才保存。

AI 不进行实时联网搜索。饮品热量均为估算；股市功能只整理用户提供的材料，不提供实时行情。AI 请求失败时，本地录入、统计、Excel 和离线 PWA 仍可使用。
